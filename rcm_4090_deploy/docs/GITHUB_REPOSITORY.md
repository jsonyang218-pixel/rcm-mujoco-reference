## Repository scope

The branch contains source code, configuration, documentation, evaluation
summaries, plots, training histories, dataset metadata, collection manifests,
and compact evaluation archives.

Large checkpoints and raw RGB-D datasets are intentionally excluded from the
normal Git repository. They require GitHub Releases, Git LFS, or an external
artifact store.
