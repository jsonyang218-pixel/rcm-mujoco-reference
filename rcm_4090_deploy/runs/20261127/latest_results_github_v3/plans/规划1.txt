**下一轮就做一件事：确定“历史纠正经验以什么比例参与训练，才能改善闭环控制”。** 按以下顺序执行，每一步有明确交付和继续条件。

**第一阶段：修正数据与评估流程**

修改以下位置：

| 文件 | 具体改动 | 验收标准 |
|---|---|---|
| `verify_experience_replay_contract.py` | 修正多检查一帧的边界错误 | 连续 20 帧、2 帧历史、16 步动作，应得到 4 个合法窗口 |
| `dataset_contract.py` | 增加共享的有效窗口筛选函数 | 同时检查轨迹、源帧、时间间隔、输入有效性 |
| `dit_experience_replay.py` | 训练与审计使用同一批有效索引 | 索引数量、内容和哈希完全一致 |
| `dit_experience_replay.py` | 缺失或未知的标签来源直接报错 | 样本不会被静默归入原始数据 |
| 验证入口 | 固定独立的 Flow 验证噪声及时间变量 | 同一权重重复验证，结果可复现 |

额外输出一份数据清单，记录：

- 原始窗口数、纠正窗口数及自然比例；
- 因轨迹边界、帧间断、时间异常、无效输入而剔除的数量；
- 纠正样本在各距离区间的分布；
- 数据路径、索引哈希和标签来源。

**完成后重新计算自然比例，原来的约 6.6% 只作为参考。**

**第二阶段：零更新复现，排除训练入口问题**

从冻结的状态注意力 v1 加载，设置：

```text
backbone_lr = 0
attention_lr = 0
weight_decay = 0
epochs = 1
steps_per_epoch = 1
```

检查三项：

1. 保存前后所有模型权重张量完全一致。
2. 同一输入、同一采样噪声下，动作输出一致。
3. 选取 3 个固定开发目标，原入口和新入口得到可复现的轨迹。

如果失败，就只排查加载、预处理、历史执行动作、归一化和采样种子，修好后再继续。

**第三阶段：运行三组回放比例实验**

三组都从**同一份冻结 v1 权重重新开始**。

| 实验编号 | 纠正样本比例 | 作用 |
|---|---:|---|
| R0 | 筛选后数据的自然比例 | 基线 |
| R10 | 10% | 小幅增加纠正经验 |
| R20 | 20% | 检查进一步增加是否有益 |

统一配置：

```text
batch_size = 16
epochs = 4
steps_per_epoch = 1000
backbone_lr = 1e-6
attention_lr = 1e-5
weight_decay = 1e-4
seed = 20261118
loss = 原来的 Flow matching
```

需要新增 `correction_ratio` 参数。抽样方法为：**每个样本按指定概率选择原始池或纠正池，再在对应池中均匀抽取。** 这样可以准确实现长期 10%、20% 的比例。

每 1000 步保存权重。首轮统一用 **4000 步权重**进行主对比，并记录验证最优权重供后续诊断。

**第四阶段：训练日志必须能解释结果**

每 100 步记录一次：

| 指标 | 用途 |
|---|---|
| 实际纠正样本比例、不同样本覆盖数 | 确认采样正确 |
| 原始样本与纠正样本各自的 loss | 检查是否牺牲原有能力 |
| 不同距离区间的误差 | 找到退化发生在哪个阶段 |
| 第一执行步的分轴动作误差、限幅比例 | 对应实际控制行为 |
| 裁剪前梯度范数、AMP 实际更新次数 | 排查数值问题 |

先保持原来的损失形式。**本轮只改变采样比例，便于判断原因。**

**第五阶段：按闭环表现筛选，再复验**

冻结 v1、R0、R10、R20，统一评估原来的 20 个开发目标。

重点比较：

| 指标 | 判断方向 |
|---|---|
| 最终误差均值、中位数、P90 | 整体是否改善 |
| 最坏误差、逐目标退化数量 | 是否牺牲少数目标 |
| 进入 100 µm 后的最长保持时间 | 是否真正提高收敛稳定性 |
| 退出时各轴速度、停稳比例 | 是否改善停止行为 |
| 安全限幅步数 | 是否引入新的异常控制 |
| 严格成功率 | 继续保留 0.35 µm＋连续三帧停稳标准 |

筛出表现最好的比例后，**该比例与 R0 各补两个训练种子**，例如 `20261119`、`20261120`。最终每组有 3 次训练结果，再判断改善是否稳定。

如果三组都明显弱于冻结 v1，下一轮固定自然比例，只检查两个因素：

- 学习率降为原来的约三分之一；
- 比较 1000、2000、4000 步权重。

这能判断是否是继续训练过度，而不是经验比例的问题。

**第六阶段：比例确定后，再补采新经验**

现有纠正数据已经被初始 v1 使用过。因此，上面的实验只能回答“历史数据如何抽样更好”。

下一轮再采集 **200 条新轨迹**：

| 场景 | 数量 | 重点 |
|---|---:|---|
| 完整接近 | 50 | 保持原有到达能力 |
| 近目标纠偏 | 70 | 不同方向、不同剩余误差 |
| 越过目标后恢复 | 40 | 减少反复穿越 |
| 到达后保持 | 40 | 减速、停稳、持续保持 |

使用训练专用目标。策略访问的状态由专家补充纠正标签；先验证专家确实能改善这些状态，再将样本加入经验池。

随后对比“原经验池”和“原经验池＋新经验”，使用选定比例、相同训练预算。这样才能验证**新增历史经验的实际价值**。

**本轮最终应交付：统一的数据索引清单、零更新复现结果、三种比例的训练日志和闭环对照表。先完成这些，再决定是否扩大采集量。**
