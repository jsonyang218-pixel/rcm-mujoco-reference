## P2 实现与比较范围

- 策略侧 `ContinuousControlTarget` 维护浮点 ABC 意图（deg、deg、mm），发送端仍为累计绝对 int32 手柄；接收端不加残差。
- 领先上限为速度×周期：0.5°、0.5°、0.1 mm；超过则将意图截断到受限值，避免积分饱和。
- 单包各轴手柄变化不超过 32；候选超过时沿用缩放序列 1、0.5、0.25、0.125、0.0625、0。
  此上限会影响大动作，G10 下 C=32 计数约37.6 µm，因此 V0/V3 差异包含累积、抗饱和及包上限的共同作用，不能归因于单一因素。
- `preview` 在隔离的模拟状态中检查协议、量化后目标、每个 2 ms 中间状态及50 ms终值；通过后提交一次。
  被拒绝的尝试不修改时钟、锚点、意图、动作历史。过期预演禁止再次提交。
- 清理条件：新目标/episode、新时钟会话、明确停止和故障。故障要求显式会话复位。
- `previous_action` 为本拍接受的 ABC 意图增量，不能替换成实际编码器移动量。记录输入分布变化。
- 策略默认仍为 `feedback`，诊断显式选 `continuous`；默认驱动保持 G15，G10 独立进程回滚。
- 教师两组复用相同 SVD/增益/制动/加速度定律与 P2 发送适配器。Oracle 使用真值位置；
  RGB-D 只使用严格视觉重建位置及固定标定，真值仅用于独立评估。教师已有累积意图不再重复积分。

保留 legacy 针具、默认 C=0/距 RCM 约4 mm起点、50 ms控制周期、2 ms积分、40 ms时间常数、
0.5 s watchdog、A/B=10°/s和C=2 mm/s。冻结目标、场景、模型结构与动作限幅不改。
新渲染固定 `offsamples=0, numslices=112, numstacks=64`，同时用于同轮所有比较。

## 指标与预登记门槛

所有阶段继续记录严格成功：误差≤0.35 µm且连续3帧实际编码器到量化目标并静止。
同时报告终值均值、中位数、最大值，≤5/10 µm命中数/实际分母，真实停稳与异常记录。
流程完成、指标改善、严格成功分别报告，不能把无异常等同于指标门禁通过。

本轮 Gate2b 是局部诊断门槛：同驱动同5目标，RGB-D减Oracle的**平均终值超额≤1 µm**，
且**每目标最大超额≤3 µm**。两条件分别保存实际值；该工程容差是本轮事先登记的诊断标准，
不代表临床指标或既有严格门槛已达标。S3的1000步结果不直接与S2的1600步终值作等预算比较。

Step4微调和Step5正式确认仍为后续分支：

- 只有胜出驱动的Gate2b通过，并确认P2下的实际剩余误差，才制定训练卡。
- 候选微调数据方案保留原草案：<200 µm的新渲染OCT覆盖层、<50 µm C-only标签核查，
  不覆盖原数据；覆盖层抽检中位误差<0.2 µm，8%清洗回放+92%原始、dagger_repeat=1。
- 训练卡须明确唯一的数据版本/样本隔离、学习率、batch size、随机种子、优化器/AMP、
  “4×1000 batches”究竟是单次4000更新还是4次独立训练、验证频率与时间预算。
  缺失项不凭空补齐，本轮不启动微调。
- 后续微调的“明确胜出”预定为同5目标同1000步终值均值至少降低10%，且严格成功数不退化；
  只有通过后才安排正式screen10及与配对基线同协议的dev20。<15/10 µm仍为愿景指标，不当作已达标。
