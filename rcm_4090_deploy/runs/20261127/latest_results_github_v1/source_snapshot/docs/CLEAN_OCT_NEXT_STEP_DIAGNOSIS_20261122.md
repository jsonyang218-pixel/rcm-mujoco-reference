## 分支与门禁

- 若命令/执行映射存在方向偏差：先在非vendored控制层定位并修正映射，再核验小动作响应；
  不通过增大训练量补偿执行错误，不自行改写固定driver。
- 若执行响应符合设计，但固定观测的动作存在偏置或噪声：优先检查近目标动作标签、
  静止/保持样本覆盖和训练/推理分布一致性，再提出有限微调卡。
- 候选短闭环门禁：3目标全部完成，终点平均误差低于配对基线，末200步平均误差降低，
  且1000→1600步平均漂移幅度下降；同时逐目标报告，避免均值掩盖单目标恶化。
  3目标结果只能用于筛选，不宣称完整成功率或泛化改善。
- 候选通过后采用固定screen10索引0–9、seeds42–51、1600步；均值低于同协议匹配基线时
  才进入dev20索引0–19、seeds42–61。screen10预算45分钟计算/50分钟外层；
  dev20预算80分钟计算/85分钟外层；单目标均900秒、4路起步最多8路。
  本文只规划这些条件阶段，不授权启动。

无论诊断或候选结果，都保留≤0.35 µm且连续3帧编码器停稳的严格成功判定。
真值仅作评估，不按真值选“最佳历史帧”或提前停止以美化指标。
不把增加Flow采样、减小动作或新停稳策略作为无代价改动；更改时需在候选卡中说明协议差异。
