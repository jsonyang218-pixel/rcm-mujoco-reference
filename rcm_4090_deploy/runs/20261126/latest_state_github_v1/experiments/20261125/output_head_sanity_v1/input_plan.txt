- Start from branch `experiment/local-oct-adaln-20261125` (commit `9fef16d`) and create a new branch `experiment/output-head-sanity-20261125`.
- Confirmed facts from `9fef16d`:
  - `F_geom_cond` (excluding visual tokens) ALREADY encodes `< 60 um` target direction with `0.73–0.77` cosine (`91%` X sign accuracy).
  - On **Training Episode 40** (`approach` from `38.061 um`, `recede` from `37.403 um`), in just 20 steps (1 s):

## Step 2 (~15m): Train Two Fast Deterministic Heads (Frozen Backbone & Same Data)
Using the exact same training dataset as `baseline_task2_step4000` and initializing/freezing the visual backbone from `baseline_task2_step4000` (so training 4,000 batches takes ~2–3 min per arm):
- **Arm R1 (Deterministic Head + Linear Action + Huber Loss)**:
  - Attach a lightweight deterministic MLP head (e.g., 3-layer MLP with LayerNorm/SiLU) taking `F_geom_cond` (plus pooled visual feature if already fused in global cond) and directly regressing the `16 × 3` action chunk (zero Gaussian sampling noise).
  - Train with Huber/SmoothL1 loss on linearly normalized actions for `4,000` batches (verify 2-batch smoke test first).
- **Arm R2 (Deterministic Head + `action_symlog` + Near-Target Direction Loss)**:
  - Same deterministic head architecture, but transform target actions with per-axis `symlog`:
    `y = sign(a) * log1p(|a| / s_axis)` with `s_axis = [0.003, 0.002, 0.001]` (A_deg, B_deg, C_mm) and exact inverse `sign(y) * s_axis * expm1(|y|)` at inference (unit-test round-trip invertibility `< 1e-7` error!).
  - Train with Huber/SmoothL1 loss in `symlog` space + a small cosine direction loss (`weight = 0.1`) on non-zero `< 80 um` frames for `4,000` batches.
