离线检查；不修改仿真器、驱动或冻结目标，不执行 motor.step。

原可达清单生成器只在整数 encoder counts 上搜索；MotorBackend 还会把目标转换为整数 handle，二者不是同一格点。
MotorBackend 没有独立摩擦或可配置死区参数；当前模型为一阶滞后、速度限制与双层整数协议量化。
