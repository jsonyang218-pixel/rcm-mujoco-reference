## 核心结论

- A 轴：非零指令但实际变化小于 `1e-6 deg` 的帧占比 **42.22–44.78%**；最小反馈步进约 **0.679–0.730 µm**。这是执行链核查触发条件，不能据此断言全部几十微米误差都是物理硬下界。
- C 轴：稳态带符号静差约 **−19.854 至 −47.796 µm**；四个目标中三个稳态窗口完全不过零。A/B 的偏差也并非均小于 5 µm，因此不满足计划情况 2 的单轴隔离条件。
- 策略/零初速教师中位幅值比：A 约 **0.275–0.578**，B 约 **1.427–1.925**，C 约 **0.279–0.303**（保存的 OCT 数值控制律口径）。不支持“策略比教师粗一个数量级、三轴全都绕零抖动”的情况 3 前提。
- 协议量化与反馈分辨率不同：A 的单 handle 针尖变化约 **5.452–5.912 µm**。冻结的可达目标只按整数 encoder 格点构造，没有验证整数 handle 可达性。
- 同一 home/session anchor、目标逆解邻域每轴 ±2 handle 搜索中，E00/E02/E06/E08/E10 的最佳端点误差分别为 **0.884、1.593、3.197、1.172、1.510 µm**，均高于严格 0.35 µm 门槛。该局部搜索不是跨所有运动学分支的全局证明；下一步由原 MotorBackend 的五目标 oracle 专家验证执行链。
- 原日志没有保存 RGB-D 几何拟合与质量，只能重算保存 OCT 向量上的教师数值控制律，另给真值 oracle 对照。不能声称精确重放原感知教师。稳态 OCT 向量与真值差的中位范数约 **9.1–9.7 µm**，也是需要保留的混杂因素。
